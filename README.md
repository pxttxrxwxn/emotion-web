
# Face Emotion Recognition Web

เว็บแอปพลิเคชันสำหรับตรวจจับอารมณ์บนใบหน้าจากกล้อง (Webcam) โดยใช้ **OpenCV** สำหรับการประมวลผลภาพ และ **YOLO11-CLS** สำหรับการจำแนกอารมณ์ (Emotion Classification)

โปรเจกต์นี้เหมาะสำหรับการศึกษา ทดลอง หรือพัฒนาเป็นระบบวิเคราะห์อารมณ์ผู้ใช้แบบเรียลไทม์ เช่น ระบบเรียนออนไลน์, UX Research, Smart Surveillance ฯลฯ

----------

##  Features

-    ตรวจจับใบหน้าแบบเรียลไทม์จากกล้องเว็บแคม
    
-    วิเคราะห์และจำแนกอารมณ์จากใบหน้า (Emotion Classification)
    
-    ประมวลผลแบบเรียลไทม์ด้วย OpenCV
    
-    ใช้โมเดล **YOLO11-CLS** สำหรับจำแนกอารมณ์
    
-    แสดงผลผ่านเว็บแอป (Web-based Interface)
    

----------

##  Supported Emotions

ตัวอย่างอารมณ์ที่รองรับ (ขึ้นอยู่กับโมเดลที่ใช้):

-   Happy
    
-   Sad
    
-   Angry
    
-   Surprise
    
-   Neutral
    
-   Fear
    
-   Disgust
    

----------

##  Tech Stack

-   **OpenCV** – จับภาพและประมวลผลใบหน้า
    
-   **YOLO11-CLS** – โมเดลจำแนกอารมณ์จากใบหน้า

-   **Next.js** (React Framework)
    
-   **TypeScript**
